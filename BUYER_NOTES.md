What you get
------------
HexSentry v1 — offline CLI secret scanner (pure Python stdlib).

How to run
----------
1. Unzip
2. `python hexsentry.py -r .`   # scan current dir recursively
3. `python hexsentry.py --json file.py`  # machine-readable

Requirements
------------
Python 3.8 or newer. No pip install needed.
